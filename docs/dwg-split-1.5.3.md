# 1.5.3：框到的完整物件直接輸出

依使用者 2026-09-18 最新要求，取消 1.5.2 疑似跨圖紙時停止輸出的限制。

- 每個圖框／矩形／封閉聚合線各建立一個 DWG。
- 依邊界輪廓執行 AutoCAD 交叉選取，將選中的模型物件交給 Wblock；不再驗證物件是否跨越其他圖紙，也不排除選中的其他圖框。
- 線段、圖塊保留完整物件。框到大型圖塊時，範圍外的內容也可能隨整個圖塊輸出；這是 WB 語意，不是裁切。
- 保留矩形與封閉聚合線模式、UCS／視圖還原。封閉 XY 邊界有效性及既有旋轉圖塊限制仍適用。
- PDF 核心與共用輸出邏輯維持 1.4.4 基準。

使用 `RECTANG` 或 `PLINE` 建立獨立封閉邊界後，在「拆分 DWG」選對應模式、選樣板、指定圖層與處理範圍。建議先輸出前兩張到新資料夾確認。

測試涵蓋各框獨立輸出、凹形輪廓與跨框完整物件回讀。實機範圍為 AutoCAD 2023；其他年版僅建置與既有文件核對，未實機驗收。

AutoCAD 2023 實测：兩矩形各一檔、凹形輪廓、完整跨框線段、UCS／視圖還原均通過；另以真實圖面副本輸出兩檔，獨立開檔物件數與選取數相同。使用者已確認 1.5.3 拆圖可用。PDF 核心、預覽、命令分流與共用設定未改动；共用邏輯與 GUI 契約檢查通過，未新增實際 PDF 列印驗收。
