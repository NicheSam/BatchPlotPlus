# BatchPlotPlus 1.4.3 介面用語檢視

介面現在固定使用三個不同概念：

- **圖框**：AutoCAD 內符合條件的圖塊或聚合線物件。
- **圖紙／頁面**：由一個圖框產生的一頁出圖結果。
- **PDF 檔案**：每頁各自成檔，或將所有頁面合併成一個多頁檔案。

| 區域 | 調整後用語 | 對應的實際行為 |
|---|---|---|
| 視窗名稱 | 批次輸出工具 Plus | 同一視窗整合 PDF 輸出與 DWG 拆分。 |
| 圖框模式 | 矩形聚合線／圖塊／封閉聚合線 | 直接說明程式用來判斷圖框的物件規則。 |
| 樣板 | 選取圖框樣板 | 樣板會提供圖塊名稱、幾何規則與自動搜尋圖層。 |
| 自動圖層 | 使用樣板圖層 | 搜尋時使用所選樣板物件的圖層。 |
| 手動圖層 | 搜尋圖層 | 可輸入完整圖層名稱或 `*`、`?`；不可留白。 |
| 個別檔案 | 每張圖紙輸出成個別 PDF 檔案 | 每個符合的圖框各產生一個 PDF。 |
| 合併檔案 | 全部圖紙合併成一個多頁 PDF | 所有符合的圖框成為同一 PDF 裡的多個頁面。 |
| 手動指定 | 指定要輸出的圖框 | 只輸出使用者明確選取且符合樣板的圖框。 |
| 清除指定 | 使用全部圖框 | 回到目前搜尋範圍內的全部符合圖框。 |
| 裝置 | PDF 輸出裝置 | 選擇 AutoCAD 的 PDF PC3 裝置。 |
| 比例 | 自動配合紙張／固定比例 | 分別對應自動縮放或輸入的 `1:n` 比例。 |
| 頁面順序 | 手動／逐列／逐欄 | 直接描述 PDF 頁面結果，避免只寫模糊的方向詞。 |
| 反轉 | 反轉順序 | 反轉最後的 PDF 頁面清單。 |
| 列印內容 | 列印物件線粗／列印物件透明度 | 兩個選項直接對應 AutoCAD 出圖開關，不改變所選 CTB／STB 出圖樣式。 |
| 圖紙方向與位置 | 自動（依圖框）／橫向／直向／再旋轉 180°／圖框置中 | 使用者可決定由圖框比例判方向，或強制橫向／直向。 |
| 搜尋範圍 | 設定搜尋範圍／搜尋整個模型 | 加入或移除模型空間的範圍過濾。 |
| 主要動作 | 開始輸出 PDF | 驗證必要設定後開始出圖。 |
| DWG 連號前綴 | 連號檔名前綴 | 圖框沒有圖名屬性時，使用此文字加上排序後的 1、2、3。 |
| DWG 連號順序 | 手動／逐列／逐欄／反轉 | 先完成排序，再指派連號檔名，避免編號與畫面位置無關。 |

## 同步補上的邏輯一致性

- 矩形聚合線模式會拒絕不是四邊直線且封閉的樣板。
- 封閉聚合線模式會拒絕未封閉的樣板。
- 手動搜尋圖層不可留白；需要全部圖層時明確輸入 `*`。
- 只有選擇合併多頁 PDF 時，合併檔名標籤與欄位才會啟用。
- 驗證訊息與 AutoCAD 指令列提示全面採用和視窗相同的用語。
- DWG 圖名屬性改為選用；缺少屬性時不再拒絕圖框，而是顯示並使用連號命名設定。
- PDF 與 DWG 各自保留排序與反轉選擇，切換頁籤不會把另一頁的設定覆寫。
- 透明度出圖可能增加 AutoCAD 圖形處理時間，預設關閉；線粗預設開啟。
