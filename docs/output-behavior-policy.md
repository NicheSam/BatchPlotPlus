# 批次出圖與拆圖功能基準

最新覆蓋要求（1.5.3）：使用者明確取消跨圖紙阻擋，要求「框到的都出圖」。DWG 交叉選取的完整模型物件直接傳入 WB，包括跨框物件及選中的其他圖框；不裁切或額外排除。保留矩形／封閉聚合線模式，PDF 與共用邏輯不变。此前 1.5.2 的阻擋要求已撤銷。

後續明確授權：使用者要求 DWG 拆圖支援矩形／封閉聚合線，並選擇沿用 WB、疑似跨入其他圖紙時停止並指出物件。此例外僅限 DWG；PDF 與共用輸出邏輯仍維持原基準。詳見 `dwg-split-1.5.2.md`。

依使用者 2026-09-18 要求，PDF 批次出圖與 DWG 拆圖的執行行為還原並固定至 1.4.4 提交 `43db0bf`。

- 還原 `PlotService.cs`、`DwgSplitService.cs`、`BatchLogic.cs`，包含選取座標、視圖、Wblock、PDF 份數、資源生命週期、設定還原、檔名及進度計算。
- 保留字型管理整合、字型按鈕及安裝遷移；字型替代仍可能影響文字外觀，與出圖／拆圖演算法是不同範圍。
- 後續批次出圖及拆圖僅允許 GUI／UIUX 調整。圖框辨識、範圍／物件選取、排序、命名、份數、輸出內容、座標轉換與參數行為變更，必須先取得另外確認；不得以「修 BUG」為由一併改動。
- GUI 修改也必須保留原控制項值與後端行為的對應。
- `tools/test_upgrade_contract.py` 核對這三個檔案的基準雜湊。測試刻意阻擋未經確認的演算法變更，不能單純重算雜湊讓檢查通過。

還原基準不等於已證明使用者圖面的單檔輸出問題已解決。必須在更換 DLL 並重開 CAD 後，以原操作驗收；不能在已載入舊 DLL 的程序中替換它，也不應自動儲存或關閉使用者圖面。
